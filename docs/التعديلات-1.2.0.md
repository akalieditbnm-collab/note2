# LocalNote 1.2.0 — ملخص التعديلات

المشروع الأصلي: <https://github.com/emirhanakdeniz/LocalNote> (Tauri v2 + React 19 + Rust/SQLite)

## 1) دعم اللغة العربية والاتجاه من اليمين إلى اليسار (i18n + RTL)

### طبقة الترجمة الجديدة `src/i18n/`
| ملف | الوظيفة |
| :--- | :--- |
| `locales.ts` | أنواع `Locale` / `Direction`، دوال `interpolate` و`pluralize`، خريطة اتجاه كل لغة |
| `locales/en.ts` | كل نصوص الواجهة بالإنجليزية (≈ 230 مفتاح) — المصدر المرجعي |
| `locales/ar.ts` | الترجمة العربية الكاملة، ومكتوبة بـ `satisfies TranslatedDictionary` حتى **يستحيل** نسيان أي مفتاح |
| `index.tsx` | `I18nProvider` + `useTranslation()` + `tGlobal()` للنصوص خارج المكوّنات (مثل رسائل الأخطاء في الـ hooks) |

- المزوّد يضبط تلقائيًا `<html lang dir data-locale data-dir>`، لذلك تعمل قواعد CSS العادية `[dir="rtl"] …` حتى للعناصر التي تُرسم في `portal` خارج شجرة React.
- الجمع (plural) مُعالج لكل من العربية والإنجليزية (`{count} كلمة` / `{count} words`).
- اختيار اللغة من **الإعدادات ← المظهر ← اللغة** يُطبّق فورًا بدون إعادة تشغيل.

### كل شاشات التطبيق أصبحت مترجمة
الشريط الجانبي، شجرة الصفحات وقوائمها، البحث السريع، ترويسة الملاحظة، فهرس المحتويات،
قوائم الكتل (Turn into / Duplicate / Cut / Copy)، منتقي لغة الكود، الإعدادات (حول/المظهر/المحرر/التخزين/النسخ الاحتياطي/الاستيراد)،
المهملات وكل نوافذ التأكيد، ورسائل الحفظ والأخطاء.

### المحرّر نفسه (BlockNote)
- تحميل قاموس BlockNote العربي الرسمي (`ar` من `@blocknote/core/locales`) وقت التشغيل حسب اللغة،
  فقائمة `/` وتلميحات التنسيق أصبحت عربية أيضًا.

### RTL في CSS
- تحويل كل الخصائص المكانية إلى **خصائص منطقية**: `inset-inline-*`, `padding-inline-*`, `margin-inline-*`, `border-inline-start`, `text-align: start`
  (لا توجد أي `margin-left/right` أو `text-align: left` متبقية في `styles.css`).
- قلب اتجاه الشريط الجانبي، والفواصل، وأشرطة التمييز، ومقابض تغيير الحجم تلقائيًا.
- عكس **الرموز الاتجاهية فقط** (سهم الشجرة، سهم الرجوع، فاصل المسار) دون عكس العنصر الحاوي — لتجنّب انقلاب التخطيط.
- الخطوط: مجموعة خطوط عربية (`Noto Naskh Arabic`, `Dubai`, `Tahoma`) تُطبّق على الواجهة العربية،
  مع إبقاء أكواد البرمجة والمسارات واختصارات الكيبورد والألوان السداسية **LTR** داخل واجهة RTL.
- النص المختلط عربي/إنجليزي يُعرض بشكل صحيح (تجنّب `unicode-bidi: isolate` على حاويات المحرّر).

### التخزين
- إعداد جديد في SQLite: `settings.language` مع أوامر Tauri جديدة `get_language` / `set_language`
  (في `src-tauri/src/settings.rs` + تسجيلها في `lib.rs`)، وتقبل وسومًا إقليمية مثل `ar-EG`.
- نسخة مرآة في `localStorage` حتى تكون **أول لوحة مرسومة** بالاتجاه الصحيح بدون وميض.

## 3) بناء ويندوز Portable + EXE عادي
- سكربت جديد `scripts/build-windows-portable.mjs` ← `npm run build:windows:portable`
  يُنتج مجلدًا `dist-portable/LocalNote-1.2.0-windows-x64-portable/` يحتوي `LocalNote.exe` + `README.txt`
  مع ملف ZIP جاهز. لا مثبّت، لا صلاحيات مدير، ولا كتابة في الريجستري.
- نفس البيانات تُستخدم في النسخة المحمولة والمثبّتة: `%LOCALAPPDATA%\LocalNote\Data\localnote.db`.
- `tauri.conf.json` أصبح يستهدف `["nsis", "app"]` فـ`npm run tauri build` يُخرج المثبّت العادي أيضًا.
- السكربت يدعم البناء المتقاطع عبر `cargo-xwin` (اكتشاف تلقائي بمتغير `CARGO_XWIN=1`).
